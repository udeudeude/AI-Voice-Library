# English voice evaluation

Use identical scripts and normalized loudness for fair comparison.

Score each voice 1-5 on:
- Naturalness and intelligibility
- Sustained narration without prosodic drift
- Expressive range without melodrama
- Accent consistency
- Names, abbreviations, numbers, quotations, and punctuation
- Artifacts, clicks, and breath/noise behavior
- Stability across different text lengths

Track synthesis speed, model footprint, license, and runtime reproducibility separately.

Do not assume a community voice file is compatible with another Kokoro model version. Test the complete model/voice pair.
